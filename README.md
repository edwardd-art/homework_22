# Skystore

Интернет-магазин для продажи плагинов и примеров кода.

## Установка и запуск

1. Клонировать репозиторий
2. Создать виртуальное окружение: `python -m venv venv`
3. Активировать: `venv\Scripts\activate` (Windows)
4. Установить зависимости: `pip install -r requirements.txt`
5. Выполнить миграции: `python manage.py migrate`
6. Запустить: `python manage.py runserver`

## Страницы

- `/` — Главная страница
- `/contacts/` — Страница с контактами

## Проверка 
- После этих настроек должны работать адреса:

http://127.0.0.1:8000/ — главная страница

http://127.0.0.1:8000/contacts/ — страница контактов
